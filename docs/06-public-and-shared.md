# Why a file doesn't show up in Public or Shared straight away

**Every file starts private.** Wherever you add it, it lands in My Files first. Nothing goes on the internet, and nobody gets a link, until you say so.

That surprises people, so here is what each place shows.

## My Files

Every file that is only yours. Files you add always arrive here.

## Public

Only files you have **published**. Publishing gives a file an address that anyone can open, without signing in.

If you click **Add files** while you are in Public, the file uploads and then you are asked whether to put it on the internet. Say yes and it appears in Public. Say no and it stays in My Files.

## Shared

Only files that have **at least one live link**. A link is for particular people: you choose whether they can only look at the file or also download it, and how long the link works.

If you click **Add files** while you are in Shared, the file uploads and the **Give a link** window opens. Make the link and the file appears in Shared. Close the window without making one and the file stays in My Files.

**A link is shown once.** Copy it when you make it. The service keeps only a scrambled copy, so it cannot show you the same link again. If you lose it, make a new one. You can stop links at any time from the file's **Give a link** window.

## Deleting a public file

A file cannot go to the Trash while it is on the internet, because its address would keep working. When you choose **Move to Trash** on a public file, you are asked to confirm, and then it is taken off the internet and moved to the Trash in one step. Its address stops working straight away.

## Quick answers

- **I uploaded in Public and it's not there.** You weren't asked yet, or you said no. It's in My Files. Right-click it and choose **Publish**.
- **I uploaded in Shared and it's not there.** Make a link for it: right-click it in My Files and choose **Give a link**.
- **How do I get a public file's address again?** Open Public, switch to the list view, and click **Copy** next to the file. Or right-click the file and choose **Copy address**.
- **How do I find a share link again?** You can't; make a new one.
