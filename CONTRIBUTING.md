# Contributing

Bug reports and feature requests are welcome as GitHub issues. Say what you expected, what happened,
and the version you are running.

JotNotes does not accept code contributions (pull requests) at the moment, so there is no contributor
agreement to sign. The code is AGPL-3.0: you are free to fork it and change it, under a name of your own.

Security problems go to security@jotnotes.com, not an issue. See `SECURITY.md`.
